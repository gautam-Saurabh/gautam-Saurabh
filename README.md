## 👋 About Me

I'm **Saurabh Kumar Gautam**, a firmware developer and hardware enthusiast focused on bridging the gap between discrete electronics and intelligent cloud systems. I enjoy turning complex concepts into robust working systems—from **microcontroller firmware and real-time control loops** to **hands-on hardware diagnostics, power management, and OTA updates**.
